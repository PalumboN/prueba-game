# ¿Sabías que...

## podés generar una github page con tu Wollok Game?

Copiate el archivo [pages.yml](.github/workflows/pages.yml) de este repo en el tuyo y pusheá.

### Algunas consideraciones al usarlo

1. Los repos deben configurar las github pages para ser deployadas desde github action: `settings -> pages -> Deploy from... -> Github Action`
